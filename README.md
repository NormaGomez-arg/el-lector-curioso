# El Lector Curioso

## Descripción

El Lector Curioso es una tienda online de libros desarrollada como Trabajo Práctico para la materia Construcción de Interfaces de Usuario de la Universidad Nacional de Hurlingham (UNAHUR).

La aplicación permite explorar un catálogo de libros, realizar búsquedas y filtros, consultar el detalle de cada producto, agregar productos al carrito y completar una compra simulada.

## Funcionalidades

- Página de inicio con identidad visual de la tienda.
- Catálogo de 20 libros.
- Búsqueda de libros por título o autor.
- Filtrado de productos por categoría.
- Acceso al catálogo filtrado desde las categorías de la página de inicio.
- Vista de detalle de cada libro mediante rutas dinámicas.
- Control de disponibilidad y stock.
- Carrito de compras.
- Aumento y disminución de cantidades.
- Eliminación de productos del carrito.
- Cálculo de subtotales, cantidad total de productos y precio total.
- Formulario controlado para finalizar la compra.
- Validaciones de los datos ingresados.
- Confirmación simulada de la compra.
- Diseño responsive para computadora, tablet y celular.

## Instalación y ejecución

1. Clonar el repositorio.

2. Ingresar a la carpeta del proyecto.

3. Instalar las dependencias:

   npm install

4. Ejecutar el proyecto:

   npm run dev

5. Abrir en el navegador la dirección local indicada por Vite.
